
# NC A&T University Management System

COMP 360 – Programming Languages  
Fall 2026

## Description
This project is a University Management System built using C++, Python, HTML, CSS, and JavaScript.

The system allows users to manage undergraduate, MS, and PhD students through a graphical interface.

## Features
- Add and view students
- Register students for courses
- View available and registered courses
- Enter grades and view GPA
- Register MS projects
- Register PhD dissertations
- Demonstrate single inheritance in C++

## How to Run
1. Download or clone the repository.
2. Make sure Python 3 and a C++ compiler (g++) are installed.
3. Run `start_windows.bat`.
4. Open http://localhost:8765 in your browser.

## Project Structure
- `backend/` – C++ student management system
- `frontend/` – HTML, CSS, and JavaScript interface
- `backend_bridge.cpp` – Connects the frontend to the C++ backend
- `server.py` – Runs the local server
- `start_windows.bat` – Starts the application
